# Test Case ID
TC-001

# Title
Verify Player WASD Movement

# Feature / Area Tested
Player Movement

# Objective
Verify that the player can move correctly using WASD keyboard input.

# Build Version
v0.01

# Tester
Grant Angell

# Test Date
7/29/26

# Preconditions
Game is launched and in correct scene

# Test Steps

1. Launch the game and enter the test scene.
2. Press W and verify the player moves forward.
3. Press S and verify the player moves backward.
4. Press A and verify the player moves left.
5. Press D and verify the player moves right.
6. Press combinations of WASD keys and verify diagonal movement.

# Expected Result
Player moves in the correct direction based on keyboard input.

# Actual Result
Player moved correctly in all tested directions.

# Status
PASS

# Notes
Gravity, physics, and Camera movement not tested due to not being in the scope of the test.
