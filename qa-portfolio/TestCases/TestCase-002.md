# Test Case ID
TC-002

# Title
Player Camera Look

# Feature / Area Tested
Player Camera

# Objective
Verify that the player can look around with the camera using mouse input

# Build Version
v0.0.1

# Tester
Grant Angell

# Test Date
7/31/26

# Preconditions
Game is launched and player is in correct scene

# Test Steps

1. Launch the game and enter the test scene
2. Move the mouse to rotate the camera view.
3. Press combinations of WASD + looking around

# Expected Result
Player camera rotates smoothly based on mouse input.
Player body rotates to match the camera direction.

# Actual Result
Player looks around smoothly but the Player's body doesnt face the camera's direction, it faces forward

# Status
FAIL
